# WIP My Windows 11 setup

# Download, flash, boot
1. Download `Windows 11 x64 US` ISO from MS website or using Media Creation Tool
2. Flash into USB drive (better using Rufus)
3. Put essential stuff: Ethernet driver if needed, NVIDIA driver, Realtek driver, Chrome setup
4. Disable secure boot, unplug Ethernet cable
5. Boot USB in UEFI mode (without CSM enabled)

# Installing
1. Press Shift+F10, open regedit, create and go to `HKEY_LOCAL_MACHINE\SYSTEM\Setup\LabConfig`, set DWORDs `BypassTPMCheck`, `BypassSecureBootCheck` to 1, close
2. Next, Next, Choose "Previous Version of Setup"
3. Configure time format and keyboard layout, Next, Install Now, (I don't have a product key), Choose `Windows 11 Pro`, Accept, Custom
4. Choose full empty drive (better NVMe) and just click next
5. After reboots, choose your country, US input method, add your second layout
6. Shift+F10, type `reg add HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\OOBE /v BypassNRO /t REG_DWORD /d 1 /f` and reboot via `shutdown /r /t 0`
7. After reboot, choose your country, US input method, add your second layout
8. Enter user name and empty password
9. Turn off all privacy settings

# Configuring
1. At desktop, open personalization settings and choose dark mode
2. In themes, configure desktop icon settings and add computer
3. Click "Adjust date and time", choose your timezone, "Show seconds in system tray clock"
4. Open cmd (Admin), `reg add "HKLM\SYSTEM\CurrentControlSet\Control\TimeZoneInformation" /v RealTimeIsUniversal /t REG_DWORD /d 1 /f`
5. Inside "Language & region", choose your regional format
6. Press Shift+Alt, click on the layout notification, configure it to the Ctrl+Shift change instead
7. Open control panel power options, chooce high performance, never turn off the display, disable fast boot
8. Rename your PC, reboot
9. Install NVIDIA (and some other required offline drivers), reboot
10. Open explorer options, default it to "This PC", remove privacy checkboxes, turn on compat view, show hidden files, remove hide extensions for known file types
11. Connect to the Internet, sync time, install all the updates (disable delivery optimizations!), reboot
12. Quit one drive
13. In settings, disable XBOX mode, Game Bar, disable notifications completely (+uncheck in additional settings), move taskbar to the left, Combine taskbar buttons When taskbar is full, show search icon only, hide Task view, Widgets and Resume
14. Unpin Edge, Store from the taskbar and remove from the desktop
15. Goto installed apps, remove Camera, Clock, Feedback Hub, 365 Copilot, Clipchamp, News, OneDrive, Teams, To Do, Outlook, Power Automate, Quick Assist, Solitaire, Sound Recorder, Sticky Notes, Weather, Xbox, XBox Live
16. Disabling UAC: Run CMD as admin -> Show more details -> Change when these notifications appear -> Never
17. Install chrome and set it as a default browser
18. Install all supported Visual C++ Redistributables (both x64 and x86) from the MS website + DirectX end-user packages
19. Install WinRAR
20. Install Winaero Tweaker in the portable mode
21. Open CMD as admin, set default profile to Command Prompt and default terminal application to Windows Terminal

# Tweaking + Disabling Security
1. Open Windows Security
2. Virus & threat protection settings -> Manage settings, uncheck everything
3. App & browser control -> Smart App Control -> Off, Reputation-based protection -> uncheck everything
4. Device security -> Core isolation, uncheck everything
5. Put Win10Tweaker inside the WinaeroTweaker dir and run it
6. Uncheck everything on the first page and apply, add first checkbox on the second page, add checkboxes for security removals on the fourth page, remove Xbox, Paint 3D, Sketch, Groove, Help from the apps
7. Open Winaero Tweaker, disable background apps, disable copilot, disable recommended in start, remove windows spotlight icon, enable startup sound, disable ads, disable app lookup in store, disable automatic maintenance, disable MRT from installing, disable smartscreen, disable user folder backup to onedrive, disable error reporting, disable new apps notification, disable auto repair at boot, enable win7-like boot menu, disable "Let's finish" screen, disable blur on sign-in, enable numlock on login screen, disable network icon on lock screen, disable web search, set wallpaper quality to 100%, show Windows version on desktop, disable MS Edge bloat, online tips in settings, enable "Do this for all" checkbox by default, ensure defender is disabled, disable auto-update store apps, disable ink workspace, disable hibernation, disable password reveal, disable telemetry, disable shortcut text and set no arrow
8. Install System Informer, set as default task manager, enable theme support
9. Open msconfig, set minimal safe boot and reboot
10. Open regedit
11. Go to `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows Defender\Features`, take ownership over it and set `TamperProtection` to 0
12. Go to `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services` and set `Start` to 4 inside `Sense`, `WdBoot`, `WdFilter`, `WdNisDrv`, `WdNisSvc`, `WinDefend`,`MDCoreSvc`
13. Go to `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\BitLocker`, create DWORD `PreventDeviceEncryption` and set to 1
14. Open msconfig, disable safe boot and set normal startup, reboot
15. Open cmd as admin, `bcdedit /set hypervisorlaunchtype off`, `sc config ucpd start= disabled`
16. Open Task Scheduler -> `Task Scheduler Library` -> `Microsoft` -> `Windows` -> `AppxDeploymentClient` -> Disable `UCPD velocity`, reboot
17. Open `C:\Program Files\WindowsApps`, take ownership and remove bloat
18. (ABSENT?) Open cmd and use ViveTool to set dark mode for some elements `vivetool /enable /id:57857165,57994323,48433719,49453572,58383338,59270880,59203365,57048231,57048237`
19. Enable new features `vivetool /enable /id:61754985,62353331,62762248,62141177,49453572,60813048,59728252,58288238`, reboot
